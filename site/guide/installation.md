# Installation

## Homebrew

```bash
brew install elliots/sqldoc/sqldoc
```

## npm (project-local)

```bash
npx @sqldoc/cli init
```

This creates a `.sqldoc/` directory in your project with the CLI and configuration.

## Binary

Download the latest release from [GitHub Releases](https://github.com/elliots/sqldoc/releases) for your platform.
